# 海报、封面与宣传主视觉

用于作品海报、角色宣传图、书籍/专辑封面及叙事项目的包装主视觉。仅在用户请求该交付时应用；角色三视图、场景结构图和视频首帧仍走各自资产路线，不自动改成装饰海报。只学习方法或写提示词时，不启动图片生成。

## 从作品核心到视觉命题

先沿用用户给定的用途、作品材料、参考身份、必需文字、画幅与美术。区分“重新设计概念”和“只修改已有版面”；局部修改保留未授权改变的图文与身份。素材缺失只标缺失，不把熟悉的同名作品或上游案例当作用户作品。

用一句话明确本图最想让观众感受到或理解的关系，再找能承载它的视觉依据：人物关系、关键物件、空间距离、尺度差、形状的相似或缺失。意象要能解释与作品的联系，而不只是添加类型片常见符号。海报中的象征是包装解释，不能反写为角色经历、剧情事实或实际空间尺寸。检查剧透边界，隐藏意象不默认泄露结局。

方向已明确时直接深化；探索确有价值时给少量可比较方向，各自改变有意义的概念或构图。不要固定生成三种，也不要把同一方案只换颜色称为三种概念。

## 先安排阅读顺序

先决定第一眼认出什么，再决定是否需要细看才能发现的第二层意思。可从以下机制中选择，不必全部使用：

- 图底关系：轮廓内外各表达一层意思，缩小后主形仍能成立。
- 共用形状：两个相关意象通过同一边缘或结构相接，避免只是互不相干的拼贴。
- 尺度或距离对照：用构图关系表达压力、隔阂或向往；不据此改变角色母版。
- 分层群像或字图关系：以主次、视线和空间组织多个主体，标题可参与几何结构，但仍须完整可读。

主视觉可以是脸、物件、群像或文字，不能因为借鉴了象征方法就强制剪影、单物件、居中或大量留白。用户要求保留人物面貌时，抽象化不得吞掉身份识别。第二层意思读不出来时，先修形状关系和主次，不再堆符号。

## 风格、色彩与文字一起设计

把风格落实为轮廓、线条、明暗、色块关系、材质与字形，不只堆艺术家名或“高级”形容词。用户指定的风格优先；题材不自动决定某种文化风格、固定配色或唯一设计师。色彩数量服务层次与情绪，不设通用上限。

仅在项目选择丝网印刷等美术方向时采用有限色块、网点或纸感；做旧、错版、复古年代都不是必需装饰。需要写实、渐变或复杂面部时保留这些要求。模拟印刷外观不等于交付了分色或可直接付印的文件；实际印刷尺寸、出血、色彩和工艺约束按当前交付要求核对。

构图前列清必需标题、署名和其他信息的准确内容，安排它们与图像的注意顺序、位置和留白。沿用[精确文字分层](post-composite-text.md)：可先生成图像底稿，再用可控排版完成文字。品牌标识使用指定的实际资产，不让模型临摹出近似标识，也不擅自补署名、宣传语或获奖信息。若文字参与轮廓，检查完整字形和语言可读性，不以图文一体为由牺牲字样准确度。

## 系列与不同画幅

先确认封面是数字正面图、印刷封面还是包含书脊/封底的整幅书衣。整幅书衣还需相应展开尺寸、装订方向与书脊宽度；出血、安全区等印前要求按实际印制交付核对，印刷正面图也可能需要。所有规格取自实际出版/印制要求，未知则保留待定，不从通用书型猜数。封底文案、条码、出版信息与书脊标题各自有明确位置和阅读方向，未授权的信息不自动补齐。正面海报完成不能冒称整套书衣或印刷文件完成。

系列作品先区分稳定项和本次变量：稳定项可为识别符号、标题层级、色彩/材质逻辑，变量可为本集意象、人物组合和主题色。系列一致不等于每张同构图，也不把某一集的具体故事或配件变成系列永久身份。

画幅取自用户或实际投放入口，不照搬“某平台永远某比例”的旧表。跨横版、竖版、方形时重排主视觉、标题、次要信息和安全区域；裁切不会自动保持阅读顺序。每个交付尺寸检查关键形状、面部、文字与标识是否完整，实际宽高是否符合要求。不拉伸角色或文字来凑比例。

## 生成、检查与交付

执行提示词组织为：用途与画幅 → 作品视觉命题 → 指定主体/参考允许继承的属性 → 第一阅读重点与可选第二层关系 → 构图及字区 → 色彩材质 → 必须保留与排除项。沿用现有[图片资产规则](music-assets.md)，不因读取外部 skill 就改用其专属服务或默认输出目录；必需输入图不可用时不能悄悄退回无参考生成。

用户请求成图时，使用当前可用图像工具实际生成、保存、查看并定向修复。分别检查：主体身份、象征是否可读、文字准确性、画幅和裁切、画面中的主次。按预期观看大小检查缩略图，同时放大检查边缘与文字；不使用统一像素阈值代替判断。

保留各独立成图，比较总览只作额外交付；不默认删除候选源图。说明哪份是图像底稿、哪份已完成排版。没有实际分层文件时不称“可编辑源稿”，没有印前检查时不称“印刷就绪”，没有传播数据时不称“最佳”或保证转化。仅修改提示词时如实交付文字，不称视觉验收通过。
