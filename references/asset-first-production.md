# 资产优先，直接制作

适用于用户明确要求先完成所需资产、由助手内部拆镜，然后直接交付分段视频提示词，不把分镜表交给用户逐项审阅的任务。它是[分段交付](segmented-prompt-delivery.md)的可选模式，不覆盖其他用户要求的普通分镜表、单镜提示词或图片包。最新明确选择优先；省略分镜审核不等于放弃内部校对，也不等于批准改剧本或批准视觉候选。

## 面向制作的两次交付

先给整份原稿需要的资产清单与逐项图片制作提示词，标清可复用文件和缺项，供用户逐项制作与绑定。身份已定的角色直接复用。只有生成计划时，不把“出资产”写成图片文件已经完成。

资产备齐后，系统在内部安排叙事部分、镜头、摄影和状态，再直接交付少量独立生成段。每段先列该制作框真正需要的角色、场景、道具与必要声音，再给可整段复制的完整视频提示词及剪辑区间。用户只需按本段清单选择实际素材、粘贴正文并生成；不增加分镜审批，也不把逐镜摄影参考图的制作变成所有任务的强制门槛。确有必要的参考缺口只针对受影响的段落说明。

内部镜头数与对外生成段数分别计算，一段可以包含多个镜头。用户提出少量段落完成一集时，优先按完整局部事件合并，避免一镜一条；目标段数仍须服从已锁原稿、时长与实际入口能力，不能借合并删动作、压台词或静默改成片。日程与期望段数留在当前项目，不固化为所有题材的同一数量或时限承诺。

## 已有稿与词库的参数快补

用户已有剧本、分段提示词或素材词库，只要把执行参数补入正文时，从现有成果继续。先辨明输入阶段：已有提示词保留段数、镜界和内容，只补执行缺项；只有剧本时内部拆镜后写提示词；只有想法且用户要求扩写时，才进入剧情创作。不能为补摄影参数重建人物小传、重写对白、重新出全部资产或开发插件；更新Skill本身也不自动触发成品改写或图片制作。

**查适用条目，不重做整套学习。** 读取本次确认稿、项目当前要求、实际选中的身份/场景/道具依据，按主体、用途、状态与版本从已定位词库检索相关条目。原稿事实、当前用户约束和已认可资产优先；词库是可复用表达，不是新剧情来源。相机、光线、焦点和材质句按本镜条件组合，不整包粘贴相互矛盾的模板。沿用可追溯且仍有效的设定；只复核变动及受影响依赖，不每次遍历所有历史或重新下载技能。没取得词库原文时不声称已读全库，先用当前实际材料完成可确定部分。

**先找缺项，再补参数。** 已确定且不冲突的参数保留。共用摄影系统、画幅及帧率在段首说明；每镜直接写本镜起止时间、景别/机位/运镜、焦距、工作光圈、主焦、景深和必要移焦、照明来源，以及执行需要的距离/高度。数字应与参考画幅、取景和人物尺度相容；未实测的距离标制作估算，已定参数不能因套模板被重置。器材信息不足但不影响原稿时可作简短制作假设，不为每个光圈或焦段反复询问。摄影选择依[摄影与光影规则](cinematography-lighting.md)，不以填写全部术语代替判断，也不把相机参数当成模型精确控制或真实感保证。

景别已给定但摄影项缺失时，调用[景别匹配](shot-camera-matching.md)取得一套符合画幅、尺度和任务的方案；简版直接并入本镜正文，增强版补机型/快门/ISO。对照已有参考图的实际取景，不能只因标签叫“大全景”就强行更换已定镜头，也不按人物/动态/环境逐镜换品牌。

关系景使人物、目标及关键环境位置可理解；表演近景优先眼睛及必要口部，操作镜优先实际接触与支撑，道具镜优先形态和状态。背景按距离自然递减，不同时要求近物与远背景全部同锐，不写“半AF”充当景深设置。只补本镜有意义的材质和受光细节，不新增雨水、烟雾、装饰物或滤镜来制造所谓电影感。

每镜输出一套确定的运镜方案，不把“推进或保持”留给执行端猜。机位固定而对焦跟随时，分别说明固定构图和跟焦对象，不把跟焦误写成相机跟拍。景别标签与实际裁切范围须相符；声音只在动作实际发生时出现，已经结束的触碰不在后续纯反应镜重复，明确的跨镜声尾另行标注。

**按事件复杂度补足，而非统一加镜。** 固定场景的单主体讲话或连续动作，优先保留既定机位及动作连续性；讲话另核对原台词、说话者、口部可见性和视线。原已明确单镜时，不为“部分包含多镜”的一般模板硬造切镜。含剧情交互的段落则核对刺激→角色感知→反应→接触/交接→结果，并追踪视线遮挡、人物位置、物品数量/归属及跨镜状态。简单表演成功只能验证其自身范围，不能替代交互剧情的实际视频验收。

逐镜知识记录只能来自本镜或此前角色实际可见、可听的事件；后镜才发生的邀请、答复或结果不能提前填入。没有新增信息时不必制造一条“获知”。动作、焦点、构图和声音中的物件位置也要与当前状态台账一致，不能台账已经交接而摄影描述仍停留在原位置。

普通切镜省略与镜内动作分开记录。原稿允许省略的非关键准备，可保留上一镜末态，再说明切镜间已经完成的变化及本镜入镜状态；不要把上一镜末态写成本镜“起始”，要求重复摆放或取物。关键接触、交易及首次获知仍按原稿可见，不能以省略为名跳过。单条记录不能同时把一次跨切变化和另一次镜内变化混为同一事件。

同一资产的数量统计全部在追踪范围内的实体，分放多处时列分布并核对加总，不只计算某容器或画面内的部分。从桌面拿到手中不使库存减少，按原稿成交移出追踪范围才递减。零库存不再入画；台账引用与入画清单独立。实际镜头场景由主体所在空间确定，望向远处另一处或使用它的参考图不表示角色已移动到那里。

原稿锁定的物理结果同样受保护。明确不变形、完整或未打开的物件，不能为增加触感擅加压痕、折痕、裂纹或漏液；用接触位置、受力支撑及角色反应交代原有动作。需要真实形变且与原稿冲突时，报告冲突，不用“轻微”掩盖结果变化。

**一次交付完整正文。** 既有原稿、对白、段内时间、成片长度、资产身份及已锁镜界不变；当参数与原动作或时长确有冲突时，指出具体位置和最小可行调整，未获改稿授权不静默重排。普通执行假设可自行补齐，只有影响原稿的实质冲突才需要用户决定。按本次交付模式，将补充内容放回每段完整提示词，核对时间、四标题、声音禁项、剪辑余量与状态交接；不只给参数补丁或让用户拼表。若项目要求Word，输出完整可编辑Word，简表按项目选择保留内部或另行展示。

此快补入口可直接在支持Skill的对话中使用，不以独立工作台、指定剧本软件、外部API或重新上传已可访问的文件为前置。调用意图示例：“用Role2Reel的已有提示词参数快补，沿用当前确认稿和已选资产，只补齐逐镜执行细节，按项目格式给完整成品。”Skill负责方法复用，具体速度仍取决于材料完整性、任务大小和工具响应，不宣称学习即训练或固定时限必出片。

## 执行依赖与边界

资产规格阶段就落实[生图摄影与输出规格](script-to-assets.md#生图摄影与输出规格)，将摄影参数与已锁像素尺寸写入图片生成正文，核对实际文件。已确认身份图直接复用，不因补摄影参数重做人物图。

1. **保护剧本。** 先锁定当前源稿、原对白及说话者、剧情关键动作、人物关系、正式成片时长和已批准的身份/美术资产。镜头细化服务原意，不能以资产难做或生成方便为由改写。用户举的秒数、相机品牌或文案形式先判断是写法示例还是明确替换指令，不能静默覆盖已有约定。
2. **先落实资产规格与文件。** 从剧本建立人物、场景、道具及必要声音的职责和状态清单；只用简短内部需求计划判断所需覆盖，不先交一份完整分镜要求用户审。先检查并复用能够覆盖要求的现有文件。用户授权实际图片制作时，调用可用图像工具完成缺项、保存实际输出并目视检查；不能用图片提示词、文件名或排期冒充已出图。具体制作按[剧本资产化](script-to-assets.md)的相关步骤执行，但不因引用该流程就额外强制整套人物档案、表情图或每镜生图。只有文字任务时不生成图片。
3. **形成内部分镜。** 在资产职责明确后完成时间、观看任务、空间、表演、物件状态及声音的逐镜计划。一个镜头一行用于内部核对；一段提示词仍可包含多个镜头，按叙事部分组织，不机械一镜一段。计划暴露关键素材缺口时，仅补受影响的规格/素材后复核依赖，不把未完成资产包称为已齐备。
4. **交付完整分段提示词。** 每段依次给本段实际资产清单、完整段落视频提示词、剪辑区间说明。主交付不展示内部简表、详细分镜板或逐镜摄影参考制作任务；需要图像制作记录时作为独立材料交付，不塞入视频提示词。用户要求内部审阅版时再提供相应内容，不默认追加人工逐镜批准。

关键资产尚有身份、结构、空间或真实感缺陷时，明确受影响范围并修复；必要项尚未完成时不能称“可直接制作定稿”。可以继续不依赖缺项的工作，或按用户要求提供明确标注的草稿。跳过人工分镜审核不授权替换已批准身份母版，不代表用户已经认可任何新图片，也不自动授权上传、发布或最终视频生成。

## 资产状态要有不同证据

| 状态 | 可支持的表述 | 不支持的表述 |
| --- | --- | --- |
| 规格已写 | 主体、用途、状态、制作要求与所需输入已明确 | 图片已生成、素材已齐 |
| 实际已生成/已有文件 | 有真实文件、版本及来源，可定位并打开 | 质量合格、身份通过 |
| 已目视检查 | 记录实际打开的版本、检查范围、通过项与未解决问题 | 用户已认可、动态视频通过 |
| 已获用户认可 | 有用户明确认可的对象、版本与适用范围 | 后续改版自动继承认可 |
| 已绑定执行输入 | 实际入口中选定了对应文件及引用职责 | 仅有本地路径就已上传，或绑定即质量通过 |

这些是分别记录的证据维度，不是见到一个字段就自动推导其他状态。助手目视可继续推进授权的普通制作，但不能代替用户认可；用户没有要求逐图审批时也不新增审批关卡。身份母版、场景依据、材质/光色参照、首尾帧各有不同职责，绑定时只继承适用属性。候选图不自动成为视频首帧，制作参考图也不自动全部上传。

## 真实感检查按对象落地

具体指出观察到的材料、尺度与受光问题，再写对应修图目标。毛发检查毛束方向、粗细变化、根部遮挡与实际光源，避免等粗绕线；眼部检查眼睑包覆与有来源反射，不靠单纯调黑瞳孔。金属、塑料、石材、织物与食物分别检查结构、粗糙度、透光和局部高光，不能所有表面共享玻璃或上漆反射。只有出现无来源的统一橙金染色、假焦糖高光时才定向纠正，保留物体本色及合理暖光；真实焦糖或油脂也不能因为用词相似被消除。别用全局去饱和、加垃圾或制造破损代替材料修复。

如实区分提示词意图、静态图片实际效果和动态视频验证。修复须保持已锁定身份与造型，不能借“更真实”换脸、改年龄、毛色或物种比例。重复失败依[资产检查与修复](script-to-assets.md#6-检查修复与继续)保留证据、定位阻塞，不无限重抽或降低标准来宣布完成。

## 一次复制即可执行的正文

完整提示词放在单独标题下的普通可编辑正文中。总说明、简表或摄影附录不能代替段内执行信息；用户复制该段完整正文后应得到：

中文交付使用【前置剪辑余量】【核心剧情及内部多镜头】【后置剪辑余量】【下一生成段的剧情状态交接】四个标题；其他交付语言可使用明确等义标题，保留这四种职责。front/core/tail/keep 是计算字段，不能代替这些叙事执行标题。内部镜头区间连续覆盖全部生成素材，首末镜各自包含可裁余量；不要只列核心区的镜头再遗漏素材头尾。

- 本段建议生成时长、素材时钟、适用的前置/核心/后置区间、核心对应成片区间与起始状态。
- 连续覆盖全段的逐镜起止时间；动作主体、目标、接触与结果；准确对白、说话者、必要现场声及指定禁项。
- 当镜景别、机位/运镜、主焦和必要移焦；本次要求的焦距、工作光圈、距离/高度及共用摄影基准直接纳入正文。器材数字注明制作意图或估算，不伪称实测或模型已精确执行。
- 本段结束时已经发生的事件、人物/物件状态与下一段剧情入口。依[分段交付](segmented-prompt-delivery.md)保留部分与镜头层级、原稿约束和独立可剪的段落，不用依赖上一生成结果的精确姿态来完成半个关键动作。

摄影参数和动作可以分行表达，但属于同一完整视频提示词；不要求用户从表格、图片编辑词或附件拼接。保持最新引用约定：自然名称与素材清单已足够时，不额外套用旧的编号或平台语法。

**时间换算先核等式。** 已锁成片长度不包含另外授权的可裁余量，不能从正片中扣掉前后余量再保留原时长标签。每段生成长度＝推荐保留长度＋前置余量＋后置余量；本段保留长度＝本段成片结束−开始。例如正片6秒、前后各1秒，素材必须是8秒，前置0—1、核心及保留1—7、后置7—8。这只是换算示例，不固定实际段长。原镜界换成素材时间时，减去本段成片起点，再加保留区起点；第一镜和最后一镜分别延长覆盖对应余量，单镜可同时覆盖两端。逐段核算后再核全片总和，不能只填对全片时长字段。

## 完成条件与日程

首镜素材起点固定为0，末镜终点为本段素材总长；单镜覆盖两端时同一镜从0连续到总长。例如正片6秒、前余量2秒、后余量1秒时，素材9秒、核心/保留2—8秒、尾余量8—9秒；不能只保证三者相加正确却漏掉一端素材。该例不改变实际任务的时长或余量选择。

交付前内部核对资产版本/职责、逐镜时间、全部原对白、摄影与焦点、状态交接和推荐剪辑区间的一致性。素材是否齐备、静态是否已检查、用户是否认可、动态视频是否验证分别报告。Word 等文件格式服从项目约定；直接制作模式的主文档不要求用户阅读内部表格才能使用。

制作日程写明依赖、预计批次和待修范围，只作为工作目标。工具排队、输出质量和返修次数未确定时，不把日期或“完成全部资产”当作结果保证，更不能因排期到点就标记通过。
