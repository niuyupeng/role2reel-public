# Extended workflow routing

Read only the route relevant to the requested artifact. Start with SKILL.md for shared scope and the common routes; these specialized routes do not authorize extra deliverables.

- For 景别识别后匹配焦段/光圈/拍法、摄影参数词典 or a concise/enhanced camera prescription, read [景别识别与摄影参数匹配](shot-camera-matching.md). Match framing, subject scale, camera position and effective sensor area before selecting one working setup. Use the linked nine-shot dictionary; camera-body/shutter/ISO profiles are optional enhancements, not a reason to change a locked camera, script or shot boundary.

- For 已有提示词只补摄影参数、沿用词库快速细化 or execution-detail enrichment of approved material, use [已有稿与词库的参数快补](asset-first-production.md#已有稿与词库的参数快补). Enter at the supplied stage, retain approved dialogue, timing and shot boundaries, reuse applicable assets and fill missing execution details in the complete prompt. Do not restart story/character creation, asset production or UI development. A request to improve this Skill does not itself request a new creative deliverable.

- For 分段提示词、每段先列资产、简易分镜表、部分包含多镜 or prompt-only screenplay delivery, read [Segmented prompt delivery](segmented-prompt-delivery.md). Preserve the hierarchy of story parts and shots inside each prompt segment; derive timing from dramatic action. Read project-local requirements first and do not generate images when only text is requested.

- For 先做齐资产再出分段提示词、内部分镜不用审阅 or an explicitly selected direct-production handoff, read [Asset-first direct production](asset-first-production.md). Keep shot planning internal and deliver each segment's assets, self-contained timed video prompt and edit ranges; retain the ordinary storyboard-table mode when requested. Actual image work must be authorized and evidenced, not inferred from a request to improve this workflow.

- For 导演定调、镜头组、动作—反应结构、情绪转折、观众信息 or integrating several directing methods, read [Directing synthesis](directing-synthesis.md). Keep story authority, asset evidence, directing choices and provider execution separate; apply the resulting decisions inside the requested deliverable rather than adding a mandatory production pipeline.

- For 项目专栏、群文件/聊天资料整理、旧项目续作、系列设定回忆 or 音频加台词生成视频提示词, read [Persistent project context](project-context.md). Select the project and continuity, inspect underlying sources, separate author decisions from drafts, then hand only applicable facts and source-bound assets with explicit approval status to the requested creative stage. Named project sections stay local rather than becoming universal skill defaults.

- For 室内空间设计、办公室布局、家具摆放、功能分区、动线规划、空间扩大或跨机位物件漂移, read [Spatial layout design](spatial-layout-design.md). Establish usable geometry and stable wall/object identities before rendering; preserve the latest user-selected layout and distinguish material edits from layout changes.

- For 场景机位套图、多方向空镜、拼贴场景参考, read the camera-direction sheet workflow in [Shot reference planning](shot-reference-planning.md#场景机位套图与拼贴交付). Bind all directions to one space; distinguish layout references from scene authority and check reverse-view geography before calling the set production-ready.

Do only the stages needed for the requested deliverable. Do not force a full production pipeline onto a narrow rewrite.

- For 剧本一键资产化、全自动资产制作、收到剧本自动生成人物/道具/场景/分镜图, read [Script-to-assets orchestration](script-to-assets.md). Execute the authorized image pipeline through real saved images and reviewed handoff, with dependency-aware reuse and resume. This mode does not require rewriting an existing script and does not authorize final video generation. A request to improve the workflow itself remains a skill-edit task.

- For 学习或检查现有参考图、素材包不完整、分镜图还是首尾帧、关键中段或细节参考, read [Shot reference planning](shot-reference-planning.md). Inspect visible properties and bind them to the correct objects and states; character references alone do not establish story coverage. Choose visual inputs per shot and generation unit. For asset count or 母空间、物件外观、内部空间、外围环境拆分, also use the visual responsibilities in [Script-to-assets orchestration](script-to-assets.md); independent entity IDs do not automatically require new images, and scene variants cannot substitute for missing asset roles.

- For角色造型、人物外观、动物/非人角色设计、服装配饰搭配、换装或身份漂移, read [Character visual development](character-visual-development.md) for silhouette, whole-look coordination, identity/look separation and reference selection; preserve established designs and the requested editing scope. The two-image contract is the default for a full character asset pack, not a reason to expand a one-image edit.
- For 作品海报、书籍/专辑封面、角色宣传图、系列主视觉 or Mondo-style packaging, read [Poster and cover design](poster-cover-design.md). Turn the established work into a readable visual concept with deliberate text placement and format adaptations; do not apply poster styling to identity sheets or ordinary video frames.
- For 新角色视觉资产创建 or a requested complete visual character asset pack, read [Character asset delivery](music-assets.md): by default deliver two actual image files: (1) a 16:9 base-design sheet with a large portrait on the left (about 38%) and full-body front/side/back views on the right (about 62%), and (2) a separate facial-expression sheet, optionally a large identity close-up beside smaller expression cells. Reusing an approved character does not trigger this two-image pack; add only references needed by the current task. Adapt portrait framing to the actual human, animal or stylized anatomy; equal scale applies within the small-cell group, not between its cells and the large portrait. The single portrait belongs on the first sheet; the multi-expression grid does not. Text-only character construction belongs to character-engine or life-paths and does not trigger images. Template-only or skill-edit requests do not authorize implicit image generation.
- For AI音乐IP、原创歌曲视觉企划、音乐MV、配歌截取、平台选题、画风、角色资产或音乐视频提示词, read [AI music IP](music-ip.md). This route inherits established characters and recorded lyrics; use only the requested layers and preserve the user’s video-production ownership. Keep ordinary screenplay and dialogue tasks on their existing routes.
- For演唱不开口、口型、动作呆板或水墨画风, read [Music performance and style](music-performance-style.md) to bind visible singing to lyrics and plan expressive movement without freezing the character.
- For剧情音乐、对白入歌、前三秒/前五秒引入, also read [Story opening and song entry](music-opening.md). Plan stimulus, visible reaction and song response before budgeting shots; do not force dialogue or sadness onto pure performance.

- First distinguish the content deliverable from its file format: a screenplay is not a storyboard, and Word/Excel does not choose the content mode. For screenplay, storyboard, or format-only delivery requests, read the deliverable boundary and screenplay contract in [references/output-contracts.md](output-contracts.md). A screenplay retains scene headings, playable action, character cues, and dialogue, without per-second labels by default. Apply shot timing and paste-ready shot syntax only to an explicitly requested storyboard/video-prompt layer.

- For transcripts, notes, treatments, narration, or AI drafts that must retain the speaker's meaning, read [references/humanization.md](humanization.md).
- For drafting or revising story prose, narrative biographies, or screenplay scenes, read [references/story-prose-craft.md](story-prose-craft.md) and [references/natural-dialogue-repair.md](natural-dialogue-repair.md) before drafting and apply their final prose review. This is not conditional on the author saying “去AI味”; keep analysis and provenance outside the creative body, and preserve the requested genre and author voice.
- For story, biography, or chapter titles, use the title-to-body check in [references/story-prose-craft.md](story-prose-craft.md). Compare the expectation each candidate creates with what the actual text delivers; preserve author-established names and do not import marketing headlines into narrative prose by default.
- For 防御性写作、anti-defensive-writing-Skill、套话、过度解释、不像人话 or flattened character voices, also read [references/natural-dialogue-repair.md](natural-dialogue-repair.md), including its scoped film adaptation of anti-defensive-writing. Diagnose scene behavior before editing vocabulary; preserve genuine uncertainty and character-specific defensiveness. Narrative focus never licenses hiding failures in evaluations or delivery reports.
- For story-workflow design, a story-to-character-to-story revision loop, or localized dialogue polishing through another skill/model, read [references/story-character-roundtrip.md](story-character-roundtrip.md). This route coordinates existing stages; it does not turn a workflow discussion into permission to rewrite a project or launch a product.
- For actual local dialogue extraction and safe reintegration, read [references/dialogue-local-workbench.md](dialogue-local-workbench.md). The helper does not invoke another model or certify semantic quality.
- For classic-film borrowing or an absurd/comedic adaptation, read [references/reference-comedy.md](reference-comedy.md); scope genre, cast, source count, and protected jokes to this project rather than making them universal defaults.
- For requested whitebox previsualization or depth-reference experiments, read [references/previs-experiments.md](previs-experiments.md). Experiments are not finished production or proven capabilities.
- For an existing fictional universe, franchise adaptation, or researched world history that will shape characters, read [references/world-grounding.md](world-grounding.md) before life-path invention. Establish the author's continuity, source versions, contested claims, and the world's actual pressures; role mechanics and fan compilations are not ready-made biographies.
- For sparse present clues, a sketch biography, “像推命一样给我几种过去,” a substantial pre-story life trajectory, or category-stereotype repair, first read [references/fatecasting.md](fatecasting.md), then [references/life-paths.md](life-paths.md) and [references/character-engine.md](character-engine.md). 命线反演 is fictional reverse inference for authors, not a claim about a real person's hidden past.
- For character-only construction from already established canon, read [references/character-engine.md](character-engine.md).
- For biography repair, growth-path review before prose, a requested brief numbered character introduction followed by a full biography, or a character whose whole past merely explains one episode, also read [references/biography-growth-review.md](biography-growth-review.md). Preserve the full life behind a short profile, distinguish unknown appearance from established facts, and stop at the author's requested review boundary.
- For multiple life strands, later chapters prompting earlier repairs, or evidence-led skill improvement, read [references/recursive-story-revision.md](recursive-story-revision.md). Develop lives beyond the job; revise within the authorized draft, then recheck affected later material. Story revision and skill revision are separate loops, neither of which grants canon approval or proves artistic improvement.
- For character-reference analysis, misleading appearances, masks, or hidden competence, also use the appearance-and-capability distinction in [references/character-engine.md](character-engine.md). Borrow a reference's specified dramatic mechanism, not its entire personality, biography, or moral alignment.
- For scene or dialogue writing, read [references/scene-dialogue.md](scene-dialogue.md). Also read [references/character-engine.md](character-engine.md) when the request requires building, repairing, or checking character state, knowledge, memory, relationships, or decision rules.
- For shot lists or storyboards, read [references/storyboard.md](storyboard.md). For professional cinematography, 镜头感、运镜、布光 or production frame planning, also read [Cinematography and lighting](cinematography-lighting.md); carry one scene geography and light-source plan into images and executable prompts. For 生图摄影参数、输出分辨率 or reusing approved identity images, apply [生图摄影与输出规格](script-to-assets.md#生图摄影与输出规格) at the image stage; reuse established identities and verify actual pixel dimensions against local requirements.
- For existing-video 片段重写、读音/对白纠错、坐站姿或动线修复, read [Local video repair](video-local-repair.md). Separate the approved state, observed defect and requested target; preserve unaffected spans and verify the actual edited result.
- For dynamic shot duration, 节奏加快但总时长不变, re-estimation, per-second beats, or a workbook that must export directly pasteable prompts, also read [references/dynamic-shot-timing.md](dynamic-shot-timing.md), [references/copy-paste-prompt-contract.md](copy-paste-prompt-contract.md), and [references/workbook-delivery-profile.md](workbook-delivery-profile.md).
- For production storyboard repair or a claim that a board is ready to generate, first read [references/source-truth-gate.md](source-truth-gate.md) and [references/atomic-shot-gate.md](atomic-shot-gate.md); for environment physics, sound carriers, continuity, or exact screen text, also read [references/physical-sound-continuity.md](physical-sound-continuity.md) and [references/post-composite-text.md](post-composite-text.md). For a high-risk review, use [references/multi-role-shot-review.md](multi-role-shot-review.md).
- For image/video-model prompts, reference media, extensions, edits, transitions, or multi-panel tasks, read [references/video-adapters.md](video-adapters.md). When the named provider is Seedance, also read [references/providers/seedance.md](providers/seedance.md) and verify current capabilities at execution time.
- For 跨段口音/声线一致、角色声音修订 or unintended spoken acting notes, also apply [voice continuity](video-adapters.md#lock-continuity-explicitly) and the [audible-text boundary](copy-paste-prompt-contract.md); distinguish stable speaker identity from momentary delivery and verify actual audio separately.
- For a specified output format, read [references/output-contracts.md](output-contracts.md).
- For audits, blind tests, or calibration against human edits, read [references/quality-gates.md](quality-gates.md).
- For learning from a series, predicting the next episode, or comparing an outline-generated draft with its finished script, read [references/episode-calibration.md](episode-calibration.md). Distinguish workflow calibration from model-weight training.
- Read [references/life-path-staged-example.md](life-path-staged-example.md) when a compact example of candidate-to-biography-to-runtime flow would resolve ambiguity. Read [references/end-to-end-example.md](end-to-end-example.md) only when a scene-to-shot example is more useful.
