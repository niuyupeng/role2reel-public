- 剧本及视觉母版来源ID、版本、hash：

## 图片与执行交付
- 若请求方向套图：方向ID / 剧情或动作职责 / 格位ID / 观察位置→目标 / 景别 / 可见地标 / 应在画外对象 / 输出文件；格数按需求。
- 输入职责：空间母版 / 仅版式参考 / 光色参考；补全空间及依据、必须排除项：
- 套图复用总览与新增视角分别计数；同空间的反打与光源核对结果、待修图及依赖：
- 拼贴总览与实际模型输入分开；若需要单幅，记录对应格位、像素尺寸及再次检查结果：
- 每镜关键帧ID与必要尾帧；每图只呈现一个动作状态：
- 参考图允许继承/必须排除的属性：
- 提示词文件及本次交付格式（逐镜复制模式用固定五段合同；完整分段模式按选定交付约定保留段内多镜），时间可行性及平台限制依据：
- 源版本变更影响的镜头/需重查资产：
